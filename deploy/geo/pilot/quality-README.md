# Проверка качества городского геопилота

`quality.py` использует только Python stdlib, ограничивает память процесса 512 MiB,
читает ответы не более 4 MiB, допускает только loopback URL и запрещает redirects.
Он не скачивает данные и не обращается к публичному Photon/Nominatim/тайлам OSM.
Нужны настоящий импортированный Photon JSONL, работающий локальный Photon и
nginx с реальными PMTiles/стилями/шрифтами. Маленькая synthetic fixture не заменяет
этот прогон. Полные данные и ответы остаются вне Git.

Из корня backend worktree (заменить пути на фактические):

```bash
python3 deploy/geo/pilot/quality.py fixtures \
  --source ../corpord-geo-pilot-data/photon/photon.jsonl \
  --output ../corpord-geo-pilot-data/photon/quality-queries.json
python3 deploy/geo/pilot/quality.py run \
  --source ../corpord-geo-pilot-data/photon/photon.jsonl \
  --fixtures ../corpord-geo-pilot-data/photon/quality-queries.json \
  --photon http://127.0.0.1:2333 --repeats 3 \
  --output ../corpord-geo-pilot-data/photon/quality-results.json
python3 deploy/geo/pilot/quality.py maps \
  --style http://127.0.0.1:8092/styles/corpord-light.json \
  --style http://127.0.0.1:8092/styles/corpord-dark.json \
  --output ../corpord-geo-pilot-data/maps/quality-results.json
```

Фикстуры воспроизводимо выбираются из **действительного импортного файла**:
до 12 русских имён (город/вокзал приоритетны), до 8 адресов, 8 префиксов,
6 опечаток, до 3 одинаковых названий и 4 запроса вне покрытия/бессмысленный запрос.
Ожидаемые ID берутся из исходных записей, а не подбираются по выдаче Photon.
Если данных недостаточно для 30–50 запросов, генератор завершается ошибкой.
Внешние запросы не обязаны давать пустой результат: улица «Московская» внутри
Екатеринбурга допустима; ни один результат не должен выходить за bbox пилота.

Проверяется GeoJSON FeatureCollection/Point, максимум 10 результатов, численные
координаты в bbox, положительные OSM ID типов N/W/R, отсутствие повторов одного
OSM объекта в ответе, принадлежность ID импортному набору и совпадение centroid.
Отчёт отдельно показывает найденный ожидаемый ID для каждого типа запроса;
отсутствие такого совпадения не превращается в техническую ошибку JSON. Код возврата
0 означает отсутствие **структурных** ошибок, а не принятие релевантности поиска.
Релевантность/точность адресов требуют прочитать `by_kind` и ручное заключение.

`p50_ms/p95_ms` — последовательные запросы одного клиента (3 повтора, без
параллельной нагрузки), включая HTTP и JSON download; первый запрос включён.
Это не cold-cache после перезагрузки и не SLA production. Полные ответы, времена,
ID, bbox и SHA256 источника/фикстур сохраняются локально для повторной проверки.
Некорректные bbox/limit фиксируются отдельно; их поведение также требует ревью.
Недоступность провайдера/таймаут адаптера проверяются существующими backend
unit tests, не отключением действующего контейнера во время этого пилота.

Карта: обе темы, style v8, источники PMTiles, атрибуция OSM, HEAD с размером/
Accept-Ranges, 206 c точными байтами заголовка PMTiles v3 и Content-Range, CORS
для localhost:3000, ETag/cache, HTTP-доступность блока кириллицы 1024–1279 для
каждого объявленного font stack, sprites при наличии. Наличие protobuf-блока
**не доказывает**, что все русские буквы нарисованы: нужен браузерный осмотр.
Проверка заголовка архива также не доказывает непустое покрытие его тайлов.

Для браузерной приёмки открыть фактическую подложку в MapLibre с центром
`[60.60, 56.84]`, zoom 12–14, обе темы и mobile 390px. Проверить дорог/зданий,
читаемые русские подписи, visible OSM attribution, отсутствие публичных сетевых
запросов и ошибок WebGL/PMTiles/glyphs. Сохранить screenshots и network evidence
вне Git. Одноцветный background style не считается приёмкой реальной карты.

Предел доказательства: совпадение с импортом подтверждает **import parity**.
OSM и производные Photon/PMTiles имеют общий источник; их взаимное совпадение
не является независимой географической истиной. Реальное расположение посадки,
полноту адресов, действующий статус вокзала и связь с внутренней остановкой нужно
подтвердить перевозчиком/редактором отдельно перед использованием для посадки.
